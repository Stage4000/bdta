How It Works
  1. Server times are stored in Eastern Time (America/New_York)
  2. JavaScript detects your browser's local timezone
  3. Times are converted and displayed in your local timezone
  4. A timezone indicator (e.g., PST, EST) is added to converted times
  5. Hovering over a time shows the original server time
